# karlhsueh/homebrew-tap

Homebrew casks for [Agent Sessions](https://github.com/karlhsueh/agent-sessions).

```sh
brew install --cask karlhsueh/tap/agent-sessions
```

Requires an Apple silicon Mac with macOS 13 or later.

The cask is generated by `scripts/update-cask.sh` in the Agent Sessions repo from each release's `SHA256SUMS`.
